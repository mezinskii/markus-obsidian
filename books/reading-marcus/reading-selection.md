# Отбор фрагментов

**Главный файл книги.** Решение о том, что входит в книгу, принимается здесь, а главы `ru/kniga-NN` следуют за ним. Корпус не трогаем: никаких `in_book` в пассажах.

Черновой шорт-лист собран скриптом по разметке корпуса (2026-09-25): балл = упражнения во фронтматтере ×3 + входящие ссылки из других карточек ×1 + упоминания в книге упражнений ×3. Квота на главу — около 20% пассажей книги Марка, не меньше 4. Фрагменты, по которым уже были письма, добавлены в любом случае (балл «письмо»). Итого **105** кандидатов, цель — 80–120.

**Решение:** `+` — берём, `−` — выкидываем, `?` — думаю. **ru / en:** `—` не начато, `черн` черновик, `гот` готово. **Письмо:** ссылка на файл из [[letters-readme|базы писем]], если по фрагменту уже было письмо.

Добавить фрагмент вне шорт-листа можно в любую главу: просто допиши строку.
