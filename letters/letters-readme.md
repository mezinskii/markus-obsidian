# Письма рассылки

База писем рассылки о *Размышлениях*. Одно письмо — один файл, русская и английская версии в одном файле: письма короткие и идут параллельно, как карточки корпуса.

Таблица всех писем — **[[letters.base|letters.base]]**: три вида — «Все письма», «В работе» (всё, что ещё не отправлено) и «Ещё не в книге» (отправленные письма о фрагментах, которые пока не переписаны в главу).

## Файлы

- `letter-NN-ББ-ФФ.md` — письмо: номер, затем фрагмент (`letter-12-10-16` — письмо 12 о X.16). Имя не совпадает с именем пассажа, поэтому ссылка `[[10-16]]` по-прежнему ведёт в корпус.
- `letter-NN-slug.md` — письмо не о фрагменте (`letter-00-kak-chitat`).
- `_templates/letter.md` — шаблон нового письма.
- `_notion-export/` — исходные архивы из Notion. Когда база проверена, их можно удалить.

## Свойства

| Поле | Что значит |
|---|---|
| `number` | номер письма в рассылке |
| `number_inferred` | `true`, если номер восстановлен по дате, а не взят из Notion — проверить |
| `status` | `idea` → `draft` → `scheduled` → `sent` |
| `date` | дата отправки |
| `passages` | фрагменты, о которых письмо; ссылки видны в корпусе как обратные |
| `kind` | `fragment` — разбор фрагмента, `intro` — вводное/методическое |
| `subject`, `preheader` | тема и прехедер по-русски |
| `subject_en`, `preheader_en` | то же по-английски |
| `lang` | в каких языках письмо есть |
| `essay_seed` | зерно для эссе (из Notion) |
| `book_chapter` | глава книги, куда письмо переписано: `"[[kniga-03]]"` |
| `open_rate` | открываемость, заполнять вручную |

## Разделы внутри письма

`## Русский` → `## Английский` → при необходимости `## Ранний вариант` (прежняя редакция, если в Notion их было две). Названия разделов те же, что в корпусе.

## Новое письмо

Создать файл `letter-NN-ББ-ФФ.md` и вставить шаблон (плагин Templates: указать в настройках папку `letters/_templates`). Статус `idea`; после отправки — `sent` и дата.

## Письма и книга

Письмо — первый черновик комментария к фрагменту в «Читая Марка Аврелия». Когда письмо переписано в главу, в `book_chapter` ставится ссылка на главу, а в [[reading-selection]] — ссылка на письмо в колонке «Письмо». Письма не правим задним числом: это архив отправленного.
